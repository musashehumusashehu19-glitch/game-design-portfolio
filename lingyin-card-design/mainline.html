01 · BRIEF & CONSTRAINTS

任务不是救强度，而是补内容、补选择，并把方案做进游戏。

导师要求设计凌音后续卡牌并落地配置。月底前完成方案与本地验证，是当时的阶段目标。

问题

英雄有热度、强度也高，但玩法内容不足。

  • 上线约半年，1技能治疗加强后达到辅助T0。
  • 卡牌多为随英雄上线的基础卡，没有形成清晰Build。
  • 实战价值集中在大招范围控制，其他技能缺少进一步塑造。
目标

用接近新英雄更新的内容量，补齐卡池与玩法。

  • 补齐3张通用数值卡与21张英雄专属卡。
  • 让单卡有吸引力、组合有化学反应。
  • 不对强势英雄提供无条件强化。
  • 同时考虑数值预算、反制和配置可行性。
01品质卡位

一局最多获得蓝紫橙各一张

02随机二选一

局内不能保证拿到指定核心卡

03软联动

单卡独立成立，组合后增量联动

04阶段结果

核心设计原则

Build不是强制套装：三张卡围绕同一战斗目标形成循环，但任何一张卡单独获得仍然有效，也不会因为缺少另一张而失效。

02 · HERO KIT

卡牌设计从英雄原本循环出发，而不是另造一套系统。

命中目标与触发“完美时刻”会积攒音量；满100进入热舞模式。原有价值高度集中于大招强控。

PASSIVE

震撼音域

影响附近敌我攻速与移速，通过命中和完美判定积攒音量，满值进入热舞模式。

设计空间：积攒速度、热舞覆盖、强化普攻与团队增益。
SKILL 01

即兴表演

放置持续范围，对敌方造成伤害、减速与易伤，并为范围内友方持续治疗。

设计空间：让音箱追随敌人干扰，或吸附队友强化辅助。
SKILL 02

动感滑步

两段可控方向的位移留下友方加速路径，并获得可击飞敌人的强化普攻。

设计空间：增加操作频率，或把功能位移转化为进攻手段。
ULTIMATE

舞力全开

持续控制范围内敌方并释放多段音浪；原本落地移动会取消施法。

设计空间：允许受限移动、增加表演窗口，同时保留打断反制。
03 · ITERATION

方案价值不只在终稿，也在每次为什么改变方向。

五个阶段逐步解决化学反应不足、表现偏保守、完美时刻被过度放大和实现风险评估过晚的问题。

V1

增益／滑步／大招

滑步流有连续位移和延迟影子控制；其余方向偏散或只是加时长。

保留滑步原型，但整体需要更明确的玩法目标和表现力。

V2

蹦蹦床流

围绕1技能范围和跳跃键形成记忆点，但敌我同步、动画和目标逻辑实现成本高。

不直接推进，暴露出创意阶段缺少可行性拆解。

V3

按技能拆为六路

每个技能分别承担两种玩法方向，避免多条Build都依赖被动和完美时刻。

由讨论形成六路框架，进入具体效果和卡位补齐。

V4

24张卡位与循环

需要保证每张卡独立有效，同时处理共享卡、品质数量和实现边界。

补齐效果、品质与Build循环，导师和同事确认方向可推进。

NOW

预算、重做与验证

两张卡存在弱效果或战斗诉求冲突；复杂卡需要先确认成本。

方案完成，优先配置现有能力可支持的效果，并建立本地测试证据。

04 · SIX BUILDS

六条Build围绕共同战斗目标组织，而不是按效果类型堆卡。

三连拍同时服务两条2技能Build，但在24张卡池中只占一个卡位。

01
PASSIVE

被动流

更快进入热舞，用热舞状态强化自身与最近队友，并提高既有橙卡利用率。

蓄能→协奏混响→洗脑节拍
循环：更快积攒音量 → 更早进入热舞 → 强化自身与队友 → 更充分利用洗脑节拍。
02
SKILL 01

干扰敌方

让静态音箱主动追踪敌人，通过范围、持续干扰、伤害与终结能力形成压迫。

扩音器→音响炸弹→终曲乐章
循环：扩大范围 → 自动追踪 → 持续减速与伤害 → 低血量终结。
03
SKILL 01

增益友方

增加音箱存储并吸附队友，围绕不同队友提供增幅与保护。

安可→聚光灯→高频音障*
循环：多次放置 → 跟随队友 → 治疗、减伤与技能防护。*橙卡当前待重做。
04
SKILL 02

频率流

增加滑行段数和完美判定机会，把操作频率转化为音量与技能循环。

炫技→三连拍→完美律动
循环：更多位移 → 更多完美判定 → 音量、免伤与冷却收益 → 再次滑行。
05
SKILL 02

进攻流

扩大路径、增加段数并用幻象复制滑行，将功能位移转化为范围伤害压力。

重步音冲→三连拍→回响共振
循环：更大路径与碰撞伤害 → 三段滑行 → 幻象延迟复制 → 扩大覆盖。
06
ULTIMATE

大招流

延长演出、允许受限移动并扩大范围，在改善开团体验的同时保留打断反制。

延时演出→巡回舞台→舞乐领域
循环：增加表演窗口 → 移动控制与完美判定减冷却 → 扩大团战覆盖。
05 · REPRESENTATIVE DESIGNS

三张代表卡分别证明操作扩展、系统循环与反制设计。

以下为最能代表个人独立设计能力的三项，不依赖完整24张卡表也能理解。

SKILL 02 · FREQUENCY

三连拍

在原两段滑行基础上增加第三段与一次完美判定，成功后自动在地面释放强化普攻，不新增方向选择负担。

  • 扩大2技能操作频率与路径价值
  • 同时服务频率流和进攻流
  • 单卡独立即可改变技能节奏
SYSTEM · PERFECT TIMING

完美律动

让各技能的完美判定统一转化为音量、防御和冷却收益，把分散操作结果收束为可持续循环。

  • 触发收益经过熟练玩家上限预算
  • 未触发时卡牌基础效果仍然成立
  • 避免只继续放大原有单点奖励
ULTIMATE · COUNTERPLAY

巡回舞台

允许凌音在大招过程中以受限移速移动，仍可被打断；成功完美判定可缩短剩余冷却。

  • 解决持续施法原地站桩问题
  • 改善开团与追击的表现力
  • 受限移速和打断保留反制窗口
06 · VALUE BUDGET

数值模型负责建立预算坐标，实测负责修正模型。

公开版用1∶1.5∶2表达蓝紫橙相对整局价值；品质不是固定职能分工。

EXPECTED MATCH VALUE

从单次效果折算到整局收益

优先使用更容易解释的技能占比或生命周期次数路径；再纳入平均目标数、覆盖率、有效率和难量化机制预算。理论值允许围绕标准上下浮动，最终仍需对标与实测。

整局价值 ≈ 单次收益 × 平均目标数 × 生命周期次数（或技能占比）× 覆盖率 × 有效率
可量化收益 + 机制预算 → 与品质标准比较 → Build合并检查 → 实测校准
CASE · 庇音

护盾与治疗分开估算

先分别计算护盾和治疗增幅，再折入目标数、技能作用窗口和有效率，避免把理论满额收益直接当成实战收益。

验证重点：其他队友筛选、持续时间与最终数值。
CASE · 巡回舞台

剩余冷却转为频率收益

根据完美判定次数估算总剩余冷却缩减，再转为技能频率增量；移动施法单独纳入机制预算。

风险控制：受限移速、可打断与熟练玩家触发上限。

BUILD 02 · ULTIMATE MOBILE

大招移动流

验证边界：两条训练场循环已跑通，不代表正式强度验证完成。

DEEP CASE · 延时演出

为多段大招追加一段表演与判定。

新增段无法触发并非单点故障。通过相似技能对照与逐段排查，确认原末段变为中间段后，需要同步更新引用、持续窗口与连续判定状态传递。
