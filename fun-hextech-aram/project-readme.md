## 命题拆解

**原题**：「面向11-15岁低龄用户的海克斯大乱斗 — 玩法、系统、关卡的设计或改变」

这是一个**典型的开放性策划命题**：
- 对象模糊（低龄用户的具体诉求？）
- 范围宽泛（玩法/系统/关卡都可以做）
- 没有标准答案

**我的拆题思路**：
1. **从个人体验起步** — 作为LOL大乱斗长期玩家，先列出自己上头的设计 vs 难受的设计
2. **推演到低龄用户** — 痛点会被怎样放大？
3. **排除法收敛切入点** — 4个维度逐一筛掉，最终聚焦海克斯符文设计
4. **梗文化作为内容填充** — 让低龄用户"想进来"

## 核心方法论 ⭐

经过两轮迭代后形成的论证骨架：

```
符文是容器 × 梗文化是内容 × 机制是护城河 × 三道防线保持续吸引
```

| 维度 | 答案 | 对应Slide |
|------|------|----------|
| **在哪里做** | 海克斯符文（低龄用户感知最强、设计空间最大） | P03 |
| **为什么这里值得做** | 长线筛选 × 对称性哲学 × 受控随机 | P04 |
| **装什么进去** | 五层梗生态（身体化/身份/空耳/反权威/情感） | P05 |
| **怎么持续吸引** | 三道防线（IP池/联动/分级更新） | P06 |
| **具体怎么落地** | 9款趣味星能 + 羁绊联动 + 5种成就路径 | P07-P12 |

## 我在项目中体现的能力

### 1. 拆题能力 — 把模糊命题变成可执行
- 排除法：从玩法/系统/关卡四个方向中筛选切入点
- 容器/内容二分法：先定"在哪里做"，再定"装什么"

### 2. 用户洞察能力 — 五层梗生态模型
- 自下而上从社交平台、KM研究、用户发言中归纳
- 每一层都对应明确的心理学/社会学依据

### 3. 跨域整合能力
- 社会学（00后社交研究）+ 文化（梗生态）+ 机制（MOBA规则）+ 数值（伤害/控制折价）
- 把分散的洞察拧成完整论证链

### 4. ⭐ 反馈应对与自我修正
- **第一轮反馈（导师/组长）**：从"AI视角"重构为"个人体验+研究骨骼"
- **第二轮反馈（组长星晟）**：补充海斗底层竞争力 + 复玩性保障两页
- **自我修正**：发现"心之刚=近战叠血量"描述不准 → 主动重新调研、修订为"歌利亚 vs 缩小引擎 + 钢化你心 vs 法强×3"两组例子

### 5. 沟通表达能力
- 双版本演讲稿（正常 vs 重点突出）应对不同时间预算
- Q&A预演覆盖4类高频追问
