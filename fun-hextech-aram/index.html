01 · FRAME THE PROBLEM

先回答“在哪里做”，
再讨论“做什么”。

原命题同时开放玩法、系统与关卡方向。我从长期大乱斗玩家的真实体验出发，用排除法比较用户感知、设计空间与改动风险，最终锁定海克斯符文作为承载趣味的容器。

CONTAINER符文是容器

低龄用户感知直接，允许单局规则显著变化。

CONTENT梗文化是内容

把熟悉的社交语言转译成进入战局的动机。

MOAT机制是护城河

筛选、随机与构筑提供成熟稳定的底座。

RETENTION三道防线

IP 池复活、羁绊衍生、底层玩法共同兜底。

WHY NOT “JUST MEMES”

梗只是入口，真正要设计的是心理需求与战斗反馈之间的映射。

一款星能必须同时满足三个条件：用户能立刻认出文化语境、行为能回应某种心理需求、机制能够被解释、反制与平衡。

FIVE-LAYER MODEL

五层梗生态

🕺身体化集体仪式
🏷身份标签自我表达
🔊空耳脑腐荒诞传播
🔥反权威消解失败
💛情感代偿陪伴保护

02 · EFFECT LIBRARY

9 款星能，
9 个可读的战斗瞬间。

每段以总览图为风格锚点：统一的冰桥场景、35°俯视镜头、小体型角色、晶体建筑和体积光。原图、人物与镜头保持固定，只让护盾、轨迹、治疗波和粒子等机制层循环运动。

LOOPED CONCEPT MOTION
以下均为机制沟通用循环演示，不是实机录屏，也不代表功能已经上线。

TRIGGER被击杀
FEEDBACK聚光、彩带、星光冲击
TRADE-OFF更易被集火，但死亡不再只有负反馈

完全隐身并高速穿行，现身首击翻倍；范围技能命中会提前暴露。把“正面操作”改造成“聪明绕后”。

隐身突袭范围反制以弱胜强

全局跟随自动拾取安全依恋

03 · SYSTEM LOOP

趣味是附加层，
不是新的强度答案。

开局选择一个趣味星能，后续仍由普通星能承担核心战斗构筑。趣味与普通星能匹配时触发软羁绊：凑到是惊喜，凑不到也不损失基础体验。

OPENING · 2 PICK 1趣味星能 × 1

决定本局体验方式与成就路径，不占普通槽位。

+
LV.3 / 6 / 9普通星能 × 3

死亡后选择，继续承担战斗构筑与强度成长。

=
IF MATCHED羁绊联动

随机凑成额外表现与策略变化，不做硬前置。

01 / ROTATION

随机池 + 加权轮换

近三局已经选过的星能降低权重，避免每局固化选择。

02 / EQUAL VALUE

体验不同，价值相近

伤害、治疗、控制与表演路径的战斗贡献控制在相近区间。

03 / SOFT SYNERGY

羁绊不是前置条件

单个星能独立成立，组合只提供额外惊喜与表达。

04 / CONTEXT

场景适配代替万能解

追击、团战与劣势局各有不同最优选择。

五种成就路径｜不只有输出才算赢

输出型芭比Q / 老六爆发击杀与翻盘高光
表演型显眼包 / 科目三被看见、制造欢笑
策略型i人 / 老六“比你聪明”的满足
坦克型刀盾 / 公主 / e人保护队友与英雄感
佛系型哈基米 / 脑腐陪伴、收集与乐子

04 · ITERATION

方案不是一次想对，
而是在反馈中变准确。

两轮组长反馈分别解决“缺少个人判断”与“缺少系统合法性”；最终又通过主动自查修正符文层级表达。

SELF-CORRECTION

主动纠错比被动认错更值钱。

发现“心之刚=近战叠血量”的表述混淆装备与符文层级后，重新核实机制，将论证改为两组更准确的“对称表象 × 不对称趣味”。

− 先讲我的创新，再寻找合理性+ 先证明底层值得保留，再讲创新层+ 用持续性机制回答“梗会不会过期”
